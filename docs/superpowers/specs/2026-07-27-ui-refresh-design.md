# GokuGoku v1.1 旧版视觉回归设计

## 目标

在不改变 v1.1 饮水计算、免打扰、下班抑制、无限提醒和撤销逻辑的前提下，让界面重新具有旧版截图中的明快、圆润和轻松感，并提高可读性。

## 视觉方向

- 主窗口由 `404 × 636` 放大到 `480 × 760`；展开设置时高度最多为 `960`，并受屏幕可用高度限制。标题栏、卡片、按钮、输入控件和正文按同一比例增大。
- 保持原版字体栈：英文和数字使用随应用内置的 `Nunito`；中文依次使用 `Yuanti SC`、`PingFang SC`、`Microsoft YaHei UI`、`Microsoft YaHei`。
- 不改成“幼圆”。通过恢复较大的字号、适中的字重、宽松行距和卡片留白，重现旧版圆润观感。
- 沿用旧版核心色：奶油白背景、浅奶油卡片、暖棕标题、鲜青绿色主按钮、黄色强调，不使用暗色蒙层或低对比灰字。
- 主界面保持“水滴角色 → 今日水分 → 主按钮 → 折叠设置”的单列结构；设置区允许滚动，主状态区不因设置项增加而继续压缩。
- 提醒窗口沿用同一字体和配色，并同步放大主要文字与操作按钮。

## 文案与信息精简

以下内容从主界面移除：

- “已喝 4000ml · 上班建议 1200ml”一整行；杯数进度保留。
- “自动按目标均匀排课，也可手动指定”。
- “手动指定 · 推荐 90 分钟”。
- “使用推荐”按钮文字及独立推荐说明区。
- “时段之外绝不提示”。
- “会议、午休期间不弹窗；可添加多段”。
- “容量修改只影响之后的打卡”。
- 设置项下方其他非必要辅助说明，仅保留设置名称、控件和必要的校验错误。

“催水间隔”保留一个紧凑分段控件：`自动 / 30分 / 45分 / 60分 / 90分`。这样保留自动推荐和手动指定能力，但不再显示推荐计算过程。

页脚“简易饮水参考 · 非医疗建议 · © 水分補給課”改为“本课对口渴负全部责任 · © 水分補給課”。

首次设置仍保留体重、杯容量、免打扰时段和目标预览，因为这些是完成资料设置所必需的信息；视觉上使用更大控件和更少装饰文字。

## 行为边界

- 本次只修改布局、视觉和可见文案。
- 自动间隔计算继续在后台工作；选择“自动”恢复自动模式，选择分钟数切换为手动模式。
- 饮水记录仍按毫升保存，杯容量修改仍只影响后续打卡。
- 免打扰、工作时间、周末设置、久坐联动、提醒无限显示与撤销规则保持不变。
- 删除说明文案不删除对应功能，也不降低输入校验和错误提示的可见性。

## 验证

- 增加静态 UI 契约测试，确保被要求删除的文案不会回归，页脚新文案和原字体栈存在。
- 运行全部核心单元测试，确保调度和数据逻辑不受视觉改动影响。
- 启动真实 Electron 应用，分别检查首次设置、主界面、展开设置、提醒窗口和撤销提示。
- 截图与用户提供的旧版截图对照，重点检查色彩明度、中文圆润感、字号、卡片面积和整体简洁度。
- 重新生成 Windows 成品及源码包，并验证新版 EXE 可以启动。
